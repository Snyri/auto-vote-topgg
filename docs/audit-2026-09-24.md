## Changes

- **Authentication readiness:** recognize managed interstitial titles/containers and require recognizable top.gg UI after a detected challenge before probing the session. Waits only observe the page, without extra navigation. Widget disappearance is no longer logged as verified access. Public Vote navigation links cannot authenticate a session.
- **Bounded session request:** a browser AbortController limits fetch/body processing to 12 seconds; an outer asynchronous timeout also covers a stalled browser connection. Malformed probe results cannot authenticate an account.
- **Partial results:** a later bot exception preserves earlier completed votes. Account-wide authentication/protection failures on a retry apply only to pending bots. Missing results become explicit failures. Duplicate bot IDs are collapsed, and IDs must use ASCII digits.
- **Cleanup:** unexpected teardown errors cannot overwrite completed voting results. A profile is still deleted after forced termination succeeds. Error screenshots are removed even without Telegram configured.
- **Scheduler:** preserve accepted run IDs and deadlines across dispatch cycles, query a known run directly when lists regress, and respect the later of a failed-run defer deadline and a prior successful future deadline. Refreshes are throttled. Artifact downloads have a streaming size cap and require exactly the expected ZIP entry.
- **Workflow:** serialize voting across branches, propagate artifact/infrastructure errors independently of the Python exit status, validate recovery depth strictly, and read bounded recovery ZIPs without extracting paths.
- **Dependency audit:** follow bounded OSV pagination; reject malformed, incomplete, or unsupported audit inputs. All 12 pinned packages passed a live OSV query. Dependency and Action versions were retained.
- **Documentation:** replace obsolete architecture images with a maintained Mermaid flow, correct multiline local configuration examples, and remove inaccurate assertions that branch protection is enforced. GitHub reported `master` unprotected and no repository rulesets.
